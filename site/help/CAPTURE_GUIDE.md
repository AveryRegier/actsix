# Help Screenshot Capture Guide

All screenshots are generated by Playwright using fake deterministic demo personas.
Run `npm run help:screenshots` after updating screenshot specs.

Desktop captures use the canonical filenames listed below (for example `members-list.png`).
Mobile captures use the same base filename with a `.mobile` suffix (for example `members-list.mobile.png`).

## Complete-List Workflow

Use this when asked to regenerate all help screenshots.

1. Run preflight inventory checks.
2. Run full capture suite (`npm run help:screenshots`).
3. Run postflight checks and resolve mismatches.

### Preflight/Postflight Inventory Checks

```bash
node -e "const fs=require('fs');const guide=fs.readFileSync('site/help/CAPTURE_GUIDE.md','utf8');const expectedDesktop=[...new Set([...guide.matchAll(/\|\s*([a-z0-9-]+\.png)\s*\|/g)].map(m=>m[1]))].sort();const expectedMobile=expectedDesktop.map(x=>x.replace(/\.png$/,'.mobile.png'));const expectedAll=[...expectedDesktop,...expectedMobile].sort();const assets=fs.readdirSync('site/help/images').filter(f=>f.endsWith('.png')).sort();const missingDesktop=expectedDesktop.filter(x=>!assets.includes(x));const missingMobile=expectedMobile.filter(x=>!assets.includes(x));const orphan=assets.filter(x=>!expectedAll.includes(x));console.log('expected-desktop',expectedDesktop.length);console.log('expected-mobile',expectedMobile.length);console.log('assets',assets.length);console.log('missing-desktop',missingDesktop.length?missingDesktop.join(', '):'none');console.log('missing-mobile',missingMobile.length?missingMobile.join(', '):'none');console.log('orphan',orphan.length?orphan.join(', '):'none');"
```

```bash
node -e "const fs=require('fs');const path=require('path');const dir='site/help/behaviors';const refs=new Set();for(const f of fs.readdirSync(dir).filter(f=>f.endsWith('.md'))){const text=fs.readFileSync(path.join(dir,f),'utf8');for(const m of text.matchAll(/\.\.\/images\/([a-z0-9-]+\.png)/g)){refs.add(m[1]);}}const guide=fs.readFileSync('site/help/CAPTURE_GUIDE.md','utf8');const expected=[...new Set([...guide.matchAll(/\|\s*([a-z0-9-]+\.png)\s*\|/g)].map(m=>m[1]))];const missingInBeh=expected.filter(x=>!refs.has(x));const extraInBeh=[...refs].filter(x=>!expected.includes(x));console.log('guide expected',expected.length);console.log('behavior refs',refs.size);console.log('missing-in-behaviors',missingInBeh.length?missingInBeh.join(', '):'none');console.log('extra-in-behaviors',extraInBeh.length?extraInBeh.join(', '):'none');"
```

Do not finish capture work if any output category is non-empty (`missing-desktop`, `missing-mobile`, `orphan`, `missing-in-behaviors`, `extra-in-behaviors`).
